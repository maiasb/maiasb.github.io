# MAIA DEVELOPMENT

Site institucional da MAIA DEVELOPMENT (CNPJ 47.831.129/0001-05), publicado em https://odevmaia.com.br via GitHub Pages. HTML, CSS e JS estáticos, sem build.

## Identidade visual

Segue o *Manual de marca v1.0* (nov/2026): fundo preto `#000`, cinzas (grafite `#222`, prata `#C2C2C2`) e vermelho `#FF0000` só como detalhe; tipografia Open Sans. Tokens em `:root` de `css/site.css`.

`img/logo-maia-development.png` (assinatura), `img/monograma.png`, `img/favicon.png`, `img/apple-touch-icon.png` e `img/og-image-v3.jpg` foram recortados do PNG aprovado (1254 px, fundo preto). Não refazer o lettering em fonte; o manual pede matriz vetorial para tamanhos pequenos.

## Estrutura

- `index.html`: home. `projetos/index.html`: lista de projetos.
- `css/site.css`, `js/site.js`: estilo e interações.
